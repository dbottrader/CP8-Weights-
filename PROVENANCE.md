# Provenance and Recovery Record

## Historical checkpoint status

The project documentation describes a historical GPT-2-class, approximately 124M-parameter CP8 geometric-transformer experiment. The exact historical checkpoint binary has not been recovered with a verified source path, binary hash, and load receipt.

Therefore:

`HISTORICAL_CP8_124M = DOCUMENTED / BINARY_UNRECOVERED`

No new checkpoint may be represented as that historical binary.
