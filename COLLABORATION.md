# Collaboration Call

The ACE / ASIN-HHC / CP8 project is seeking collaborators who value open technical work, strict evidence boundaries, and transparent attribution.

## Priority workstreams

### Independent model reproduction

Rebuild the declared micro architecture, verify the loader, design an approved public corpus, record environment details, and publish hashes and failures.

### Model and dataset engineering

Help create a licensed, versioned CP8 corpus; improve tokenization; train the planned 124M line; build held-out evaluations; and produce model cards and dataset cards.

### Receipt-driven agent infrastructure

Extend worker/validator nodes, deterministic replay, signed receipts, capability documents, sandboxing, observability, and fault-injection tests.

### Governance, privacy, and security

Review release boundaries, licensing, personal-data handling, threat models, key management, promotion gates, and claims language.

### HHC contribution accounting

Develop transparent credit policies, duplicate-work detection, review and appeal procedures, and auditable links between accepted artifacts and internal ledger events.

## How to contribute

1. Open an issue describing the exact artifact or test you propose.
2. State your assumptions, dependencies, and licensing.
3. Keep capability claims separate from authority claims.
4. Include commands, environment details, hashes, and receipts.
5. Report failed reproductions as useful evidence rather than hiding them.

## Community principle

**Fast exploration. Hard receipts. No fake authority. Reality retains veto.**
